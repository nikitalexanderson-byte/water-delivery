# ФАРВАТЕР для Android

Минимальная версия Android 8.0 (API 26). Проект использует Kotlin, Jetpack Compose Material 3 и Gradle Wrapper. Для сборки нужны JDK 21 или совместимый JBR из Android Studio, Android SDK Platform 36.1 и Build Tools. Сборка CI находится в `.github/workflows/android.yml`.

**Windows.** Из корня репозитория выполните:

```powershell
.\apps\android\build-local.ps1
```

Скрипт собирает рабочие исходники через Gradle во временном каталоге и сохраняет проверенную сборку в `.local/apk/farvater-driver-debug.apk`. Такой запуск подходит для синхронизируемых папок, в которых Windows добавляет `desktop.ini` в каталоги Android-ресурсов.

Для физического телефона по USB выполните из того же каталога:

```powershell
.\apps\android\build-local.ps1 -Usb
```

Результат — `.local/apk/farvater-driver-usb-debug.apk` с адресом `http://127.0.0.1:18019` внутри телефона. Команды установки и подключения приведены ниже. Обе сборки включают локальную карту из `packages/route-map/static`.

**Linux или macOS.** Из каталога `apps/android` выполните:

```sh
bash gradlew testDebugUnitTest assembleDebug
```

APK будет в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions выполняет те же задачи и сохраняет APK в артефактах запуска.

**Подключение к backend.** По умолчанию debug-сборка использует `http://10.0.2.2:8080` — адрес компьютера из стандартного Android Emulator. При другом порте или способе подключения задайте `ANDROID_API_URL` перед сборкой. Например, на личном тестовом телефоне с USB-пробросом локального порта используйте `http://127.0.0.1:8080`. Приложение ставится через Android Studio или системный установщик APK. Для входа используйте `driver1@farvater.test` либо `driver2@farvater.test` и пароль из `DEMO_PASSWORD`.

Новый экспедитор принимает приглашение команды в веб-панели. После входа Android получает адрес производства и маршруты своей команды.

Руководитель, диспетчер и оператор входят с теми же почтой и паролем, что в веб-панели. Приложение открывает рабочий кабинет своей роли, адаптированный для узкого экрана. При первом входе в команду зарегистрируйтесь или примите приглашение через веб-панель. Для руководителя и диспетчера выгрузка CSV сохраняется через системное окно Android.

**Проверка рейса.** Подтвердите выход в «Моей смене» и отметьте «С грузчиком», если он едет с вами. Изменить состав экипажа можно до первого выезда. После распределения диспетчером нажмите «Обновить смену». На завтра маршрут открывается с 18:00 по времени базы. При отправлении укажите время выезда и загрузку. При доставке подтвердите оплату и количество принятой тары либо укажите причину неудачи.

Кнопка «Заказ на месте» доступна во время рейса в разделах «Смена» и «Остатки». Для нового клиента введите имя, телефон, адрес и категорию. Существующему клиенту можно выдать дополнительную воду из его карточки. Выберите свободный бренд, укажите количества и оплату, затем нажмите «Уже выдано». После последнего возврата на базу нажмите «Сдать тару и деньги». Отчёт показывает совпадение или расхождение и разбивку по воде, таре и видам оплаты.

**Бренды воды.** Каждая позиция заказа показывает бренд, число бутылей и цену. На погрузке проверьте количество по каждому бренду и при необходимости добавьте запас из каталога. Подтверждение доставки относится ко всем строкам заказа. При допродаже выберите бренд из свободного остатка рейса. При сдаче введите пересчитанные количества отдельно, включая нули. Отчёт покажет излишек или недостачу по каждому бренду даже при совпадении общего числа бутылей.

### Маршрут и карта

Чтобы посмотреть карту сразу после входа, откройте «Маршрут → Учебный маршрут». Два примера содержат девять остановок. Кнопка «К моим рейсам» возвращает к опубликованному рабочему маршруту. «Моё местоположение» запрашивает разрешение Android и показывает отметку телефона с точностью в метрах.

Внизу доступны «Смена», «Маршрут», «Остатки» и «Профиль». На экране смены находится следующее действие. В маршруте переключайтесь между «Списком» и «Картой рейсов». При двух рейсах можно просмотреть обе последовательности или выбрать одну. На карточке остановки видны окно, вода к выдаче и введённые оператором подсказки для подъезда, офиса, домофона и въезда. Основной и дополнительный номера доступны, когда они указаны в заказе.

Уличная карта доступна и без рейсов. На рабочей карте нажмите «Моё местоположение» и разрешите определение местоположения. Обновление позиции прекращается при уходе с экрана. Учебная карта использует только координаты остановок и базы.

Номера маркеров соответствуют последовательности доставки. Схема показывает порядок точек, географическая карта использует координаты из заказа. Для базы задайте `BASE_LAT` и `BASE_LON` на сервере. По умолчанию приложение запрашивает уличные тайлы OpenStreetMap при доступной сети. Установка `MAP_TILES_ENABLED=false` включает автономный обзор Московского региона Natural Earth. Общий пакет Leaflet 1.9.4, обзор и схема поставляются в APK.

В географическом режиме сервер возвращает автомобильный путь, расстояние и приблизительное время в движении. Кнопка «Посмотреть перегоны» раскрывает расстояние и время между каждой парой точек. Время разгрузки в эту оценку не входит. При недоступности сервиса остаются маркеры, схема и список. Для внешней навигации выберите рейс и нажмите «Открыть в Яндекс Картах». При известных координатах базы маршрут начинается и заканчивается на производстве.

**Звонки.** Синяя кнопка у номера открывает наборщик. Поддерживаемое приложение МТТ Бизнес выбирается автоматически при первой настройке. В профиле или в карточке точки можно выбрать другой наборщик или «Спрашивать при звонке».

**Связь и напоминания.** Последний открытый день и токен хранятся на устройстве в зашифрованном виде. При потере ответа на запись приложение хранит её тело и UUID до восстановления связи. Кнопка повтора отправляет сохранённую операцию. Открытый экран обновляет день раз в минуту. При получении опубликованного маршрута приложение ставит системные напоминания за 90 минут до ETA и пересчитывает их при следующем обновлении. Если до ETA осталось меньше 90 минут, сигнал запрашивается при синхронизации. Для Android 13+ включите разрешение в разделе «Профиль → Напоминания о звонках». Экономия батареи может сдвинуть сигнал. После перезагрузки устройства откройте приложение для восстановления расписания.

**Проверка на устройстве, 23 ноября 2026.** На Samsung Galaxy A56 5G (Android 17, API 37) через USB проверены вход, подтверждение смены, получение маршрута, фактическая загрузка двух брендов, доставка, возврат и сдача смены. Для 3 доставленных бутылей и 1 новой тары Android и кабинет диспетчера показали 1 350 ₽ наличными, 1 полную бутыль к возврату и 2 пустых. Android зарегистрировал уведомления об изменении маршрута и звонке, когда до ETA оставалось менее 90 минут.

При подтверждении этой доставки тестовый ретранслятор оборвал ответ после успешной записи сервером. После остановки и повторного открытия приложения без сети сохранилась кнопка повтора. После восстановления связи рейс завершился с одной доставкой, одним списанием и одной оплатой. Полный голосовой проход с TalkBack и точность срабатывания напоминания при длительном сне телефона остаются отдельными проверками.

### Установка и подключение по USB

Запустите локальный API на компьютере по инструкции в корневом README. Подключите телефон, включите отладку по USB и подтвердите разрешение на экране телефона. Выполните команды из корня репозитория. При выборе устройства укажите идентификатор физического телефона из списка ADB. Параметр `-s` адресует каждую команду этому устройству.

```powershell
$adb = Join-Path $env:LOCALAPPDATA 'Android\Sdk\platform-tools\adb.exe'
& $adb devices -l
$deviceId = Read-Host 'ID телефона из списка ADB'
& $adb -s $deviceId install -r .\.local\apk\farvater-driver-usb-debug.apk
& $adb -s $deviceId reverse tcp:18019 tcp:8080
& $adb -s $deviceId reverse --list
```

Откройте «ФАРВАТЕР» на телефоне и войдите под тестовым водителем. После переподключения кабеля повторите `reverse`, если правило отсутствует в списке. При другом порте API измените `tcp:8080` в правой части команды. Для изолированного прогона можно направить порт телефона на отдельный локальный API с тестовой базой. После проверки выйдите из тестового кабинета перед переключением на обычный стенд.
