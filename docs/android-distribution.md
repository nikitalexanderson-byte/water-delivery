# Установка WaySlate с сайта

WaySlate распространяется как подписанный APK по HTTPS. На странице входа есть ссылка «Скачать WaySlate для Android». Android запрашивает подтверждение установки. При первом запуске установщика система может запросить разрешение для источника, из которого открыт файл. [Распространение APK с сайта](https://developer.android.com/distribute/marketing-tools/alternative-distribution)

## Проверки выпуска

- GitHub Actions собирает релизный APK, проверяет подпись, структуру Android-манифеста, разрешения и доступность компонентов. В релизе отключены HTTP, резервное копирование данных приложения и режим отладки.
- Встроенное обновление загружается через HTTPS, проверяет размер файла, SHA-256, номер сборки, идентификатор пакета и совпадение сертификата подписи. Установку выполняет системный установщик по действию пользователя.
- Перед показом проверьте скачивание с сайта и запуск на Android с включённой Play Защитой. Google может предложить отправить незнакомую сборку на дополнительную проверку. Вердикт выносит Play Защита. [Google Play Protect](https://support.google.com/googleplay/answer/2812853)

На Windows можно собрать APK для проверки из корня репозитория. Скрипт сохраняет неподписанный файл в `.local/apk/wayslate-release-unsigned.apk`. Подписанный выпуск собирает `Release WaySlate` для выбранной среды.

```powershell
$env:ANDROID_API_URL = 'https://81-177-166-235.sslip.io'
$env:ANDROID_VERSION_CODE = '12'
.\apps\android\build-local.ps1 -Release
```

`/api/app-release` сообщает номер, размер и SHA-256 опубликованного файла. Проверить сертификат скачанного APK можно командой `apksigner verify --verbose --print-certs wayslate.apk` из Android SDK Build Tools.

## Регистрация разработчика вне магазина

Владелец может подтвердить личность и связать пакет с сертификатом в Android Developer Console. Для текущего канала пакет `ru.farvater.driver`, а SHA-256 сертификата подписанного стендового APK — `222a041a9f8b5ebcafbaf5ecbbf73d95255c4ff83ef749ed37202f6063a45f47`. По запросу консоли владелец подписывает тем же ключом APK с выданным фрагментом подтверждения. Регистрируется идентификатор пакета. Файл для пользователей по-прежнему выдаёт сайт. [Регистрация в Android Developer Console](https://developer.android.com/developer-verification/guides/android-developer-console)

Перед выдачей приложения рабочим командам опубликуйте политику конфиденциальности с реквизитами владельца и фактическими правилами работы с данными. Геопозицию активного рейса экспедитор включает сам. Её видят оператор и администратор той же команды. Пользователь может остановить передачу из приложения или уведомления Android.
